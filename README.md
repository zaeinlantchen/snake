# LunaUI —— 贪吃蛇客户端（LVGL v8.3，JSON 协议）

运行在 Samsung S5P6818 开发板的多人联机贪吃蛇客户端界面与逻辑（800×480，ARGB8888）。

C/S 架构：服务端持有全部游戏逻辑（见 `server/`）；客户端负责渲染服务端下发的
状态，并把玩家操作（摇杆方向、房间选择、退出）以 **JSON** 发给服务端。

## 界面流程

```
用户名屏    ->  输入用户名 + Start（自动连接服务器 192.168.72.23:5000）
   |
主菜单      ->  左侧 单人模式 | 右侧 多人模式
   |
多人模式    ->  房间选择屏（点击房间/按房间号加入 / 随机加入 / 创建房间 / 返回）
   |
游戏屏      ->  顶部得分/无敌 + 右上“退出”回主菜单 + 左侧虚拟摇杆 + 棋盘
```

- 单人模式：服务端为当前玩家开一间专属房间（单人游玩）。
- 多人模式：房间号由服务端维护，可指定房间号或随机加入。

## 目录结构

```
LunaUI/
├── snakeInit.c/h   入口协调器（连接、JSON 收发、屏幕切换、摇杆/按钮转消息）
├── page/           界面布局
│   ├── inc/ui_page.h   界面对外接口 + 回调
│   └── src/
│       ├── ui_menu.c   用户名屏 + 主菜单（单人/多人）
│       ├── ui_room.c   多人房间选择屏
│       └── ui_game.c   游戏屏：Canvas + 摇杆 + 退出 + 无敌显示
├── net/            网络模块
│   ├── net.h / net.c   TCP 客户端 + 后台线程 + 线程安全消息队列
│   ├── protocol.h      JSON 协议（与 server/inc/protocol.h 一致）
│   └── lib/cJSON.*     cJSON 库
└── snake/          蛇结构模块
    ├── snake.h / snake.c  蛇/食物/世界状态数据结构 + JSON STATE 解析
```

## 控制

- **摇杆**（左侧）：拖动虚拟摇杆，蛇自动朝该方向移动；松开后保持该方向继续移动。
- **退出**（游戏屏右上）：离开房间，回到主菜单。

## 无敌（8s）

- 蛇出生随机在地图任意位置，带 8 秒无敌：期间不死亡、可穿过其它蛇（其它蛇也不会上
  当受伤害）；顶部显示 `Invincible: Ns` 倒计时；无敌中的蛇带白色描边。

## 编译

沿用仓库根目录 `zaeinGui/Makefile`（已扫描 `LunaUI` 下所有 `.c`，含 `net/lib/cJSON.c`）。

```sh
cd zaeinGui
make CC=arm-linux-gcc     # 生成 ARM 版 zaeinGUI
```

> 界面文字全英文（LVGL 内置 Montserrat 字体只含 ASCII/符号）；中文仅出现在注释/日志。
